# Public Showcase — Engagement and Contributor Metrics

**Scope:** Public GitHub repository only. No tracking pixels, personal analytics, private laboratory information, or visitor identity collection.

## Traffic (owner-access required)

Open [Insights → Traffic](https://github.com/HAKOSARI/sakarya-aerospace--engineering-showcase/graphs/traffic) while signed in with repository permissions. Record the 14-day **views**, **unique visitors**, **clones**, and **unique cloners**. This connector cannot currently read the private traffic endpoint. Do not confuse stars or forks with visitors.

## Contributions (public GitHub records)

- **First-time contributors:** unique PR authors whose first accepted PR merged in the reporting period; exclude maintainers and bots, define exclusions explicitly.
- **PR review time:** median time from PR creation to first substantive maintainer review (not a bot), among PRs reviewed in period.
- **PR merge time:** median time from PR creation to merge, for merged PRs in period.
- **Starter issue conversion:** number of good-first-issue PRs opened and merged, reported separately.
- **Demo verification:** CI passes the seven preset outcomes and six priority-order cases. CI passing does not prove cross-browser accessibility.

**Targets, not achieved metrics:** visitor can understand the purpose in 30 seconds, run a browser example in 5 minutes, and prepare a narrowly scoped first contribution in 30 minutes. Track usability with voluntary feedback, not hidden telemetry.
